# proxy 自定义规则
#
# 格式：<动作> <路径> [响应体]
#   mock    本地伪造响应，不转发
#   forward 原样转发给真实服务器
#   block   直接断开连接
#
# 路径末尾加 * 表示前缀匹配，自上而下第一条命中生效。
# # 开头是注释，行首加 disabled| 可以临时停用某一条。
#
# ── 要让 proxy 生效，必须先声明域名 ──────────────────────
# 以数字开头的行是 hosts 条目，会被合并进 hosts。
# 只有这里声明过的域名，反代才会为它签发证书并处理请求。
# 没有这一行，proxy 即使启用也不会拦截任何流量。
#
# 例子（把域名换成你要拦的）：
#   127.0.0.1 api.example.com
#
# ── 规则例子 ────────────────────────────────────────────
#   mock    /api/check_update  {"code":0,"data":{"haveUpdate":false}}
#   forward /api/*
#   block   /ads/*
